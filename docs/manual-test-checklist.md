# 직접 확인할 목록

자동 테스트로는 확인할 수 없는, 실제 창과 재부팅이 필요한 항목이에요.
`publish/WindowFix.exe`로 확인하세요. 결과 칸에 ✅ / ❌와 메모를 적어 주세요.

## 개발 중 이미 확인한 것 (2026-11-13)
- 메인 창과 저장 창이 실제 모니터 2대(2560×1440)를 물리 해상도로 그림
- 저장 창이 서브모니터의 디스코드·카톡을 미리 체크함
- 별도 프로세스의 테스트 창으로 확인:
  - 옮기면 1초 안에 되돌아옴
  - 연속 8번 옮기면 5번 되돌린 뒤 포기함
  - 대기 중 CPU 0
- 가장자리 탭: 서브모니터 오른쪽에 붙음. 클릭으로 풀기/다시 고정이 됨
- 배포 exe: 실행됨, 두 번 실행해도 하나만 뜸, 고정이 꺼져 있으면 창을 닫을 때 종료됨
