# WindowFix

**디스코드, 카카오톡처럼 늘 켜 두는 창을 원하는 자리에 고정해 주는 Windows 앱이에요.**

듀얼 모니터에 창을 예쁘게 배치해 놔도, 테두리를 실수로 건드리거나 컴퓨터를 껐다 켜면 금방 흐트러지죠. WindowFix는 그 배치를 저장해 두고, 창이 움직이면 바로 제자리로 돌려놓고, 컴퓨터를 켤 때마다 다시 맞춰 줘요.

## 다운로드

**[최신 버전 받기 (Releases)](https://github.com/Mino7406/WindowFix/releases/latest)** → `WindowFix.exe`

- 설치가 필요 없어요. 파일 하나만 실행하면 돼요. (.NET도 따로 설치할 필요 없어요)
- Windows 10 / 11
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명이 없는 개인 프로그램이라 뜨는 안내예요)

## 사용법 — 세 단계면 끝

1. 디스코드, 카톡 같은 창을 평소 쓰는 위치와 크기로 놓아요.
2. WindowFix에서 **[+ 새 배치 생성]** → 고정할 창에 체크 → **저장하기**
3. **[🔒 창 고정]**을 켜요.

이제 창을 실수로 끌거나 크기를 바꿔도 손을 떼는 순간 원래 자리로 돌아와요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 배치 저장 | 창 위치·크기를 배치로 저장하고, 여러 배치를 만들어 골라 쓸 수 있어요. |
| 창 고정 | 움직이거나 크기가 바뀌면 바로 되돌려요. 최대화·스냅도 되돌려요. |
| 시작 프로그램 | 컴퓨터를 켜면 창이 늦게 떠도 기다렸다가 제자리에 놓아요. 결과는 Windows 알림으로 알려 줘요(설정에서 끌 수 있어요). |
| 창 고정 위젯 | 화면 가장자리의 얇은 막대예요. 누르면 잠깐 풀리고, 다시 누르면 원래 자리로 돌아가요. |
| 배치 수정 | 미리보기에서 모니터를 누르면 그 모니터의 배치를 바로 고칠 수 있어요. |
| 창별 옵션 | 항상 위에 두기, 최소화 막기, 꺼지면 다시 켜기, 꺼져 있으면 자동으로 켜기 |
| 관리자 권한 | 게임처럼 관리자 권한으로 켜지는 창도 고정할 수 있어요. (설정에서 켜기) |
| 테마 | Windows 설정 따라가기 / 라이트 / 다크 |
| 자동 업데이트 | 새 버전이 나오면 알려 주고, 버튼 하나로 업데이트해요. 배치와 설정은 그대로예요. |

## 자주 묻는 질문

**창을 닫았는데 계속 켜져 있어요.**
창 고정이 켜져 있으면 창을 닫아도 뒤에서 계속 지켜요. 완전히 끄려면 시스템 트레이 아이콘 메뉴의 **WindowFix 끝내기**를 누르거나, 창 고정을 끈 뒤 창을 닫으세요.

**게임 창이 고정되지 않아요.**
관리자 권한으로 켜진 창은 WindowFix도 관리자 권한이어야 옮길 수 있어요. 설정에서 **항상 관리자 권한으로 실행**을 켜세요.

**업데이트하면 배치가 사라지나요?**
아니요. 배치와 설정은 `%APPDATA%\WindowFix\config.json`에 따로 저장돼서, 프로그램을 바꿔도 그대로 남아요.

**지우고 싶어요.**
설정에서 **시작 프로그램으로 설정**과 **항상 관리자 권한으로 실행**을 끄고, `WindowFix.exe`를 지우세요. 설정까지 지우려면 `%APPDATA%\WindowFix` 폴더도 지우면 돼요.

## 개발자용

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)가 필요해요.

```bash
dotnet test
```

```bash
dotnet publish src/WindowFix -c Release -r win-x64 -o publish
```

- `src/WindowFix.Core` — 창 찾기, 좌표 변환, 배치 적용, 고정 판단, 시작 복원, 업데이트 (테스트 가능한 로직 + Win32)
- `src/WindowFix` — WPF 화면 (메인 창, 배치 창, 고정 위젯, 트레이)
- `tests/WindowFix.Core.Tests` — xUnit 테스트
- `docs/` — 설계 문서, 인수인계(`HANDOFF.md`), 화면 문구 목록(`ui-text.md`), 수동 점검표

### 새 버전 배포(릴리스) 방법

앱은 켤 때와 하루 한 번 GitHub의 최신 릴리스를 확인해요.

1. `src/WindowFix/WindowFix.csproj`의 `<Version>`을 올려요. 예: `0.1.0` → `0.2.0`
2. `dotnet publish src/WindowFix -c Release -r win-x64 -o publish`
3. GitHub **Releases → Draft a new release**
   - 태그: `v0.2.0` (`<Version>`과 같은 숫자, 앞에 `v`)
   - 파일: `publish/WindowFix.exe`를 **이름 그대로** 올려요.
   - pre-release는 끄고 **Publish release**. (임시 저장·미리보기 릴리스는 업데이트로 안내되지 않아요)
